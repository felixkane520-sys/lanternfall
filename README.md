Lanternfall is an original arena survival game in plain static files: you are the night-watch lantern keeper holding a paper-cut night sky over a sleeping town. Move with WASD or the arrow keys, aim with the mouse, and hold the mouse button or Space to loose light-seeds at the ember sprites. Survive eight waves to reach dawn and win; every fourth wave an Ember Matriarch boss appears. Fallen embers drop XP sparks — level up and choose one of three upgrades. All art is drawn in code on a canvas, all sound is synthesized with WebAudio, and the game runs fully offline in a desktop browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
